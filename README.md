# Back to the Future

Erkundungs-Werkzeug aus der Reihe Panta Rey: Wann sah BTC oder Gold schon einmal so aus wie heute, und wie ging es danach weiter? Zeigt vergangene Häufigkeiten, keine Vorhersage.

- Seite: https://panta-rey.github.io/BTTF/bttf.html
- Dateien: `bttf.html` und `gold-history.json` müssen im selben Ordner liegen.
- Geschwister: [Dashboard](https://panta-rey.github.io/Dashboard/dashboard.html) · [BTC-Ampel](https://panta-rey.github.io/BTC/)
